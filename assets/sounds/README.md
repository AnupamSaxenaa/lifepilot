# Custom Notification Sound

Place your custom notification sound file here as `custom_alert.wav`.

Requirements:
- Format: WAV (PCM 16-bit)
- Duration: 1-3 seconds
- Sample rate: 44100 Hz
- The file MUST be named `custom_alert.wav` to match the app.json config.

You can download free notification sounds from:
- https://notificationsounds.com/
- https://freesound.org/
